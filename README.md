# Tetocord

[**Baixar o projeto Tetocord.zip**](https://github.com/pedrohenriquefronza10-code/Mikucord/raw/refs/heads/main/Tetocord.zip)

O arquivo inclui codigo-fonte, configuracoes de exemplo, migracoes e instrucoes para instalar o aplicativo. Nao e necessario publicar o ambiente do Codex para baixar ou executar o projeto.

Depois de extrair, comece pelo arquivo **Tetocord/docs/quickstart.md**. Requisitos: Node.js 22.19+, npm e Docker com Compose v2. Credenciais locais sao geradas pelo setup; nao ha senha ou conta padrao.

Para acesso dos amigos pela internet, configure dominio, HTTPS e portas de midia conforme o guia. GIFs usam uma chave Tenor propria; push depende da permissao/configuracao do navegador. Consulte **docs/validation.md** no ZIP para os resultados e limites da validacao.

O checksum SHA-256 esta em **Tetocord.zip.sha256** neste repositorio.
